# Control de Cuentas

Aplicación para llevar el control de cuentas por pagar y por cobrar.

## Requisitos

- Node.js 18+
- npm

## Instalación

```bash
npm install
```

## Ejecutar en desarrollo

```bash
npm run dev
```

La app estará disponible en http://localhost:3000

## Construcción de producción

```bash
npm run build
```

## Vista previa de producción

```bash
npm run preview
```
